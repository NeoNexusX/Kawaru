# 架构文档总览

本文档是 Kawaru 系统全部架构图的导航入口。所有架构图以交互式 HTML 形式存放在 [docs/frameworkmap](../frameworkmap/) 目录下，本文档提供分类索引、阅读路径和通用图例说明。

## 1. 系统简介

Kawaru 是一个质谱数据管理与分析平台，核心业务包括文件上传下载、算法处理、聚类分析和数据可视化。系统采用 FastAPI + Celery + Aliyun FC 的异步架构，计算密集型任务全部交给函数计算（FC）执行，后端服务器只负责校验、调度和状态管理。

## 3. 推荐阅读路径

### 3.1 新开发者（第一天）

1. 先读 [贡献指南](贡献指南.md) 了解分支策略和本地开发流程
2. 再读 [Docker 部署架构](../frameworkmap/kawaru-docker-deploy.html) 了解系统由哪些容器组成
3. 然后按顺序读 [文件上传](核心业务API架构-文件上传.md) → [文件下载](核心业务API架构-文件下载.md) → [算法处理](核心业务API架构-算法处理.md)，理解核心业务链路

### 3.2 业务开发者（日常开发）

- 修改文件相关代码：读 [文件存储与生命周期架构](文件存储与生命周期架构.md)
- 修改处理相关代码：读 [算法处理与实验管理架构](算法处理与实验管理架构.md)
- 修改用户/权限代码：读 [用户认证安全与邮件架构](用户认证安全与邮件架构.md)
- 涉及异步任务：读 [异步任务与回调架构](异步任务与回调架构.md)

### 3.3 运维人员

1. [系统部署与数据库演进架构](系统部署与数据库演进架构.md) 了解 Docker Compose 拓扑和 CI/CD 流程
2. [部署指南](部署指南.md) 查看具体操作命令

## 4. 图例与通用约定

架构图中使用的图标和连线有统一含义：

### 4.1 组件类型

| 图标颜色 | 含义 | 典型组件 |
|---------|------|---------|
| 蓝色 | 后端服务 | FastAPI、Celery Worker、Celery Beat |
| 绿色 | 外部用户/客户端 | Browser、API client |
| 紫色/灰色 | 数据库 | MariaDB、Redis |
| 橙色/云朵 | 云服务 | Aliyun OSS、Aliyun FC |
| 红色/锁 | 安全相关 | JWT 认证、Token 验证、权限校验 |
| 黄色/消息 | 消息队列 | Redis Broker |

### 4.2 连线类型

| 连线样式 | 含义 |
|---------|------|
| 实线箭头 | 同步调用（请求→响应） |
| 虚线箭头 | 异步操作（投递任务、写缓存等） |
| 加粗/强调箭头 | 关键路径或主要数据流 |
| 红色/安全箭头 | 鉴权或安全校验 |

### 4.3 常见缩写

| 缩写 | 全称 | 说明 |
|------|------|------|
| API | FastAPI 后端服务 | 处理 HTTP 请求，运行在 :8000 |
| Worker | Celery Worker | 异步任务执行器，10 个线程 |
| Beat | Celery Beat | 定时任务调度器，使用 RedBeat |
| Redis | Redis 8.4 | 缓存 + 消息队列，AOF 持久化 |
| MariaDB | MariaDB 11.4 | 业务数据库 |
| OSS | Aliyun Object Storage Service | 对象存储，存放所有业务文件 |
| FC | Aliyun Function Compute | 函数计算，执行解包、算法处理等计算任务 |
| STS | Security Token Service | 临时访问凭证，用于客户端直连 OSS |
| JWT | JSON Web Token | 用户认证令牌 |
| Zarr | Zarr 格式 | 分块数组格式，用于存储处理结果 |

### 4.4 同步调用、异步任务和回调的区别

| 模式 | 说明 | 举例 |
|------|------|------|
| 同步调用 | API 直接调用并等待结果返回 | API 查询 MariaDB |
| 异步任务 | API 投递任务到 Redis，Worker 消费执行，API 不等待结果 | 发送邮件、触发 FC |
| 回调 | FC 执行完后主动通知 API 结果 | 算法处理完成回调、上传解包回调 |
